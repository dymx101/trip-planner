🛂 四国陆路跨国口岸通关要点速查

1. 新加坡 ➔ 马来西亚（新山苏丹依斯干达大厦 JB CIQ）

签证政策：持中国普通护照享马来西亚免签（入境前 3 天内在线填写 MDAC 数字入境卡）。

通关流程：兀兰关卡刷护照出境新加坡 ➔ 乘跨界穿梭车过桥 ➔ 新山 CIQ 刷脸/人工通道盖章入境马来西亚。

2. 马来西亚 ➔ 泰国（黑木山 Bukit Kayu Hitam / 沙道 Sadao 口岸）

签证政策：中泰互免签证协定生效，中国公民免签入境泰国停留不超过 30 天。

通关流程：夜班长途大巴清晨直抵黑木山 ICQS 检查站，全员带随身贵重物品下车办理马出境，随后步行至泰国柜台免签盖章入境，大巴在泰方出口接驳直奔合艾。

3. 泰国 ➔ 老挝（国际列车直通廊开 - 万象坎萨瓦站）

签证政策：老挝对中国护照实行落地签（Visa on Arrival，费用约 40 美元，需备白底照片）或提前办理 B3 电子签（eVisa）。

通关流程：列车在泰国边境廊开站停靠办理泰国出境手续 ➔ 列车驶过第一泰老友谊大桥 ➔ 直抵万象坎萨瓦站下车办理老挝入境手续，一站式省心！

4. 老挝 ➔ 中国（中老铁路磨丁 / 磨憨铁路口岸大厅）

口岸规格：国家一级铁路客运国际口岸，“两地两检”高效模式。

通关流程：乘坐 D888 次动车抵达磨丁站，下车办理老挝出境盖章 ➔ 上车穿过友谊隧道 ➔ 抵达中国磨憨铁路口岸联检大厅，中国护照走自助电子闸机秒速入境并过海关 X 光机，全程约 1.5 小时无缝完成！
